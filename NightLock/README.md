# NightLock

Locks distracting apps on your computer during nightly windows so you stop getting
pulled into them.

- [`windows/`](windows/README.md) for Windows 10/11. Double-click `NightLock.cmd` to open
  the settings window: pick apps by icon, block websites in Chrome, Edge and Brave, set
  weeknight and weekend windows, press Start or Stop.
- [`macos/`](macos/README.md) for macOS. Command-line only, single nightly window, apps
  only. Run `./install.sh`.
